# 实验 01：逐步看懂 SGD、动量与 Adam

这个实验只需要 Python 3.9 或更新版本。**无需安装 NumPy、PyTorch，无需下载数据，也无需 GPU。**

先用纸笔能算的函数理解更新，再把同一套优化器用到一个小型线性模型。
仓库根目录原来的 README 保持原样；本实验的全部文件位于 `experiments/sgd_vs_adam/`。

## 1. 直接运行

在终端执行：

```bash
git clone https://github.com/wskk/Hello-World.git
cd Hello-World/experiments/sgd_vs_adam
python3 run_experiment.py
```

如果已经下载过仓库，进入已有仓库，先执行 `git pull`，再进入实验目录。
Windows 上如果 `python3` 命令不可用，使用 `py` 或 `python` 替代。
也可直接在 GitHub 仓库页面用 **Code → Download ZIP** 下载解压，进入同一目录运行。

程序会显示每种优化器前 5 步的数值，同时在 `results/` 下生成：

| 文件 | 用途 |
|---|---|
| `summary.md` | 三个实验的初始/最终损失、最终参数、学习率扫描汇总 |
| `scalar_trace.csv` | 一维实验的每一步、每个中间量 |
| `anisotropic_trace.csv` | 二维实验的每一步，每个参数单独一行 |
| `linear_trace.csv` | 小批量线性回归，包含实际批次编号和批次损失 |
| `*_loss.svg` | 可在浏览器打开的损失曲线，纵轴为对数尺度 |
| `learning_rate_sweep.csv` | 三种优化器在同一组学习率上的全部结果，包含不稳定的运行 |
| `config.json` | 起点、步数、超参数、数据和实际批次顺序，便于复现 |

先看本文第 3 节，然后看 [已运行的示例结果](example_results/summary.md)。
`example_results/` 是本次默认运行留下的完整结果；你自己的结果默认写入被 Git 忽略的 `results/`。
相同输出目录中的同名结果文件会被覆盖；需要保留多次实验时，请设置不同的 `--out-dir`。

只看一维实验的全部 20 步：

```bash
python3 run_experiment.py --problem scalar --print-steps 20
```

改变一个因素，比较前后结果：

```bash
python3 run_experiment.py --problem anisotropic --lr 0.1 --out-dir results/lr_01
python3 run_experiment.py --problem linear --steps 120 --seed 7 --out-dir results/longer
python3 run_experiment.py --problem scalar --beta1 0 --out-dir results/no_first_moment_memory
```

最后一条将 Adam 的一阶矩历史记忆关闭，但仍保留二阶矩历史与偏差修正，因此它仍然不等同于 SGD。
命令行 `--help` 可查看所有选项；`--steps` 是**更新次数**，不是 epoch。

## 2. 三个实验分别解决什么问题

| 实验 | 目标/数据 | 相同起点 | 默认步数 / lr | 观察重点 |
|---|---|---|---|---|
| `scalar` | L(w)=(w−3)²/2；梯度 g=w−3；最小值在 w=3 | w=0 | 20 / 0.1 | 手算前两步；同一 lr 下 SGD 可以更快 |
| `anisotropic` | L(x,y)=(x²+100y²)/2；梯度为 (x,100y)；最小值在 (0,0) | (3,3) | 100 / 0.01 | 梯度尺度不同，Adam 如何逐参数归一化 |
| `linear` | 6 个点，y=2x+1；预测值为 wx+b；最优 (w,b)=(2,1) | (0,0) | 60 / 0.1 | 真正的小批量梯度、同一数据顺序、训练循环 |

前两个实验没有随机样本：使用 SGD 的无动量更新规则时，实际做的是**确定性的梯度下降**。
第三个实验每轮打乱数据、每批 2 个样本，才包含小批量随机梯度；6 个样本意味着每个 epoch 更新 3 次，60 步就是 20 个 epoch。

三个实验内的各优化器都从同一起点、全零历史状态开始；每次学习率试验也完全重置。
线性回归的批次顺序先用固定种子 7 生成一次，再交给各优化器使用。
**相同批次不意味着后续梯度相同**：参数走到不同位置后，必须在各自的新位置重新求梯度。

## 3. 先手算一维的第一步

初始 w=0，L=4.5，梯度 g=w−3=−3。学习率 α=0.1。

统一记法：`update` 是有符号的“减去量”，`w_new = w_old - update`。
所以 `update` 为负数时，w 反而增加。

### 无动量 SGD

```text
update = α × g = 0.1 × (-3) = -0.3
w_new = 0 - (-0.3) = 0.3
L_new = (0.3 - 3)^2 / 2 = 3.645
```

### SGD 加动量（代码中称为 Momentum）

本实验采用未乘 `(1−μ)` 的缓冲区写法，μ=0.9：

```text
u_new = μ × u_old + g
update = α × u_new
```

初始 u=0，因此第一步也是 u=−3、w=0.3。
第二步 g=−2.7，u=0.9×(−3)+(−2.7)=−5.4，于是 w=0.3−0.1×(−5.4)=0.84。

这里的 u 是累积动量；Adam 的 m 使用下面带 `(1−β₁)` 的指数平均写法。
当 μ=β₁、历史梯度完全相同且都从零开始时，m=(1−β₁)u。
本实验中两者的轨迹随后不同，所以不能把它们的缓冲区大小或同一数值学习率直接视为等价。

### Adam：一阶矩与二阶矩一起参与更新

默认 β₁=0.9，β₂=0.999，ε=10⁻⁸。每个参数都有自己的一份 m 和 v。

```text
m_t = β₁ × m_(t-1) + (1-β₁) × g_t
v_t = β₂ × v_(t-1) + (1-β₂) × g_t²
m_hat = m_t / (1-β₁^t)
v_hat = v_t / (1-β₂^t)
update = α × m_hat / (sqrt(v_hat) + ε)
w_new = w_old - update
```

| 第一步的量 | 代入计算 | 结果 |
|---|---|---:|
| 当前梯度 g | 0−3 | −3 |
| 梯度平方 g² | (−3)² | 9 |
| 一阶矩 m | 0.9×0+0.1×(−3) | −0.3 |
| 二阶原点矩 v | 0.999×0+0.001×9 | 0.009 |
| 修正后的一阶矩 m_hat | −0.3/(1−0.9¹) | −3 |
| 修正后的二阶矩 v_hat | 0.009/(1−0.999¹) | 9 |
| 分母 | √9+10⁻⁸ | 3.00000001 |
| update | 0.1×(−3)/3.00000001 | 约 −0.1 |
| w_new | 0−(约 −0.1) | 约 0.1 |
| L_new | (约 0.1−3)²/2 | 约 4.205 |

一阶矩保留梯度的正负方向，平滑近期梯度；二阶原点矩保留平方后的大小信息，用于按参数缩放。
**二阶矩不是二阶导数，也不等于方差**；方差需要减去均值的平方。
即便目标是确定性的，也能对沿途梯度做这样的指数平均，不需要真的抽样估计一个已知概率分布。

偏差修正针对 m/v 从零初始化造成的早期缩小；它不保证非平稳梯度序列的任何统计估计都无偏。
本例第一步修正后，m_hat 就是当前梯度、v_hat 就是当前梯度平方。

### 再核对 Adam 第二步

忽略 ε 带来的极小差异，第一步后 w≈0.1，因此第二步 g≈−2.9：

```text
m₂ ≈ 0.9×(-0.3)+0.1×(-2.9) = -0.56
v₂ ≈ 0.999×0.009+0.001×(-2.9)^2 = 0.017401
m_hat₂ ≈ -0.56/(1-0.9²) = -2.947368421
v_hat₂ ≈ 0.017401/(1-0.999²) = 8.704852426
update₂ ≈ -0.099897293
w₂ ≈ 0.199897292
L₂ ≈ 3.920287588
```

SGD 第二步到 0.57，Momentum 到 0.84，Adam 到约 0.199897292。
它们的第二步梯度已经不同：SGD/Momentum 从 0.3 求梯度，Adam 从约 0.1 求梯度。
CSV 保留 ε 和浮点运算后的实际值；上述手算显示的是近似值。

## 4. 二维实验：为什么要“逐参数”看二阶矩

起点 (3,3) 的梯度是 (3,300)。默认 lr=0.01：

| 量 | x 方向 | y 方向 |
|---|---:|---:|
| 梯度 | 3 | 300 |
| Adam 第一步 m_hat | 3 | 300 |
| Adam 第一步 v_hat | 9 | 90000 |
| Adam 分母（忽略 ε） | 3 | 300 |
| Adam direction_scale=lr/分母 | 约 0.00333333 | 约 0.0000333333 |
| Adam 实际减去量 | 约 0.01 | 约 0.01 |
| SGD 实际减去量 | 0.03 | 3 |

y 的梯度大 100 倍，Adam 的分母也大约 100 倍，因此第一步实际更新量相近。
这说明它在按历史梯度尺度归一化，**不意味着梯度大的方向一定走得更少，也不意味着所有步骤的更新量都固定等于 lr**。
Adam 的分子、分母都随历史变化。

默认 SGD 第一步恰好把 y 从 3 移到最优的 0，这是该二次函数与 lr=0.01 的特殊配合。
Momentum 第二步虽然 y 梯度已经为 0，旧动量仍让 y 移到 −2.7，完整损失暂时上升。
这也是为什么带历史状态的优化器不保证每一步损失下降。

把 lr 改成 0.1 后，SGD 的 y 更新为 y_new=−9y，尺度持续放大。
无动量 SGD 在这个二维目标上使用固定学习率渐近收敛，需要 0<lr<0.02；这个范围来自 y_new=(1−100lr)y。
它只适用于这个目标和更新规则，不是对所有问题的学习率要求。

## 5. 线性回归如何连接反向传播

数据为：

| 样本编号（从 0 开始） | x | y |
|---|---:|---:|
| 0 | −3 | −5 |
| 1 | −2 | −3 |
| 2 | −1 | −1 |
| 3 | 1 | 3 |
| 4 | 2 | 5 |
| 5 | 3 | 7 |

对某个批次 B：

```text
prediction_i = w*x_i + b               # 前向传播
error_i = prediction_i - y_i
L_B = mean(error_i²) / 2
dL_B/dw = mean(error_i*x_i)             # 链式法则，手写反向传播
dL_B/db = mean(error_i)
```

每步先选批次，再计算预测、损失和新梯度，最后优化器更新 w/b。
代码每步直接生成新的梯度列表，不累积旧梯度，因此不需要框架中的 `zero_grad()`。
这与 MLP 中“前向传播 → 计算损失 → 反向传播 → 更新参数”的结构相通；这里没有隐藏层和自动求导框架。

绘图和 `loss_before/loss_after` 始终在**全部 6 个点**上评价当前参数。
本批的损失单独存为 `batch_loss_before/batch_loss_after`，避免用不同批次的损失误判优化进度。
同一步两行对应 w/b，完整损失重复显示两次；不能把这两行当作两次更新。

## 6. 实际结果与结论的边界

本次默认运行的最终完整目标损失（保留约 6 位有效数字）：

| 实验 | SGD | Momentum | Adam |
|---|---:|---:|---:|
| 一维，20 步，lr=0.1 | 0.0665140 | 0.534580 | 0.626484 |
| 二维，100 步，lr=0.01 | 0.602909 | 0.000851394 | 214.811 |
| 线性回归，60 步，lr=0.1 | 6.47927×10⁻⁷ | 1.20985 | 0.000249471 |

**默认结果没有显示 Adam 优于 SGD。**在一维实验中，SGD 第一步移动 0.3，而 Adam 约移动 0.1；选定的 lr 对 Adam 而言更保守。
这同样不能推出 SGD 总是优于 Adam。

程序还自动尝试共同的 lr 网格：`0.001, 0.003, 0.01, 0.018, 0.03, 0.1, 0.3, 1.0`。
每种优化器都尝试全部 8 个候选，步数与批次保持一致；选择按**最后一步训练损失**，不挑过程中最低的那一步。
例如二维实验中，网格上 SGD 最好的是 lr=0.018、最终损失约 0.118990，Adam 最好的是 lr=0.3、约 0.00391964；Momentum 在本次网格中更低，约 0.000753064。
换学习率后排序会变化，说明单一超参数比较不足以给算法排名。

这里还有两个刻意保留的特殊情况：一维 SGD 取 lr=1 能一步到达 w=3；线性数据完全无噪声，含 x=−1 和 x=1 的一批，其梯度恰好是 (w−2,b−1)，lr=1 也能一步走到最优解（浮点舍入误差除外）。
不要把这些巧合当作通用建议。

这些实验不支持下列推论：

- Adam 必然收敛、更快、或者比 SGD 的最终解更好；反向的绝对结论也不成立。
- 同一个数值 lr 就给了各算法等价的实际步长，或已经完成充分调参。
- 二阶矩越大，实际参数更新一定越小；它还取决于分子 m_hat。
- 训练损失更低就代表新数据表现更好；本实验没有独立验证集或测试集。
- 这个小问题的结论可直接推广到 MLP、大模型、带噪声数据或不同批次大小。
- 相同步数就代表相同运行耗时；这里没有做计时基准，Adam 还需要额外的历史状态。

本实验中步数固定，没有学习率衰减、权重衰减、正则化、Nesterov 或 AMSGrad。
`nonfinite` 表示浮点数溢出/非有限值并中止；`completed` 只表示完成指定步数，**不代表已经收敛**。
请把它当作理解公式的实验台。

## 7. CSV 字段与代码入口

| 字段 | 含义 |
|---|---|
| `step`, `epoch`, `batch_ids`, `parameter` | 更新编号、所处轮次、样本编号、参数名称；纯函数实验的 epoch/batch 留空 |
| `parameter_before`, `gradient`, `gradient_sq` | 更新前参数、当前位置的梯度、梯度平方 |
| `momentum_before`, `momentum_buffer` | Momentum 更新前后的累积动量 u；其他优化器留空 |
| `m_before`, `m` | Adam 更新前后的一阶矩估计 |
| `v_before`, `v` | Adam 更新前后的二阶原点矩估计 |
| `m_hat`, `v_hat`, `denominator` | Adam 的偏差修正值和 √v_hat+ε |
| `direction`, `direction_scale` | SGD 用 g、Momentum 用 u、Adam 用 m_hat；对应乘数为 lr、lr、lr/分母 |
| `update`, `parameter_after` | update=direction_scale×direction；新参数=旧参数−update |
| `loss_before`, `loss_after` | 更新前后在完整目标/全部训练数据上的损失 |
| `batch_loss_before`, `batch_loss_after` | 更新前后在当前同一批次上的损失 |

`direction_scale` 不是“当前梯度直接乘上的实际学习率”：Adam 实际乘的是 m_hat。
当梯度及历史 v 都为 0 时，该列可为 lr/ε 的大数，但 m_hat=0，实际更新仍为 0；可以在线性实验 b 的第一步看到。
同样，历史 m 不为零时，当前梯度为零也未必停止移动。

建议阅读顺序：

1. [optimizers.py](optimizers.py)：三个 `step()`，是核心公式。
2. [run_experiment.py](run_experiment.py)：`Problem.gradient()` 与 `run()`，对应求梯度和训练循环。
3. [example_results/scalar_trace.csv](example_results/scalar_trace.csv)：对照手算，把第 1、2 步核对一遍。
4. [example_results/summary.md](example_results/summary.md)：看曲线和网格，再改变一个设置重新运行。

运行数值检查：

```bash
python3 -m unittest -v
```

检查包括手算更新值、Adam 两步高精度参考值、一维 SGD 解析解、逐参数状态、有限差分验证梯度、相同批次/状态重置，以及非有限运行不能误报成功。
